# Optimización Responsive - DS3 Comunicaciones

Este proyecto presenta la transformación de la ficha técnica del producto "6-1427200-4" a un formato responsivo, tomando como base y mejorando la estructura del archivo "C9200L-24P-4G-E.html".

## Mejoras Implementadas
* Diseño Mobile-First: Adaptación completa para celulares y escritorio.
* Modularización: Separación de componentes reutilizables ('navbar', 'footer', 'breadcrumb', 'submenu') mediante JavaScript para facilitar el mantenimiento.
* Rendimiento: Optimización de estilos utilizando Tailwind CSS.
* UI/UX: Implementación de un menú lateral (sidebar) funcional para navegación móvil y submenús desplegables.

## Tecnologías
* HTML5 / Tailwind CSS
* JavaScript
* Component Loader (Carga dinámica de HTML)
